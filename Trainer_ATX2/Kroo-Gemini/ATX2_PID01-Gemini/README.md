# 🤖 คู่มือการใช้งานหุ่นยนต์เดินตามเส้นด้วยระบบ PID (สำหรับบอร์ด ATX2)

## 📑 สารบัญ
1. 📚 **พจนานุกรมคำสั่ง (Function Glossary)** - อธิบายความหมายของแต่ละคำสั่ง
2. 🛠️ **คู่มือการทดสอบทีละขั้นตอน (Sequential Testing Guide)** - เช็คลิสต์ก่อนลงสนามจริง
3. 🎛️ **คู่มือการจูน PID (PID Tuning Guide)** - วิธีปรับตัวเลขให้หุ่นวิ่งเนียนและเร็ว

---

## ภาคที่ 1: 📚 พจนานุกรมคำสั่ง (Function Glossary)
คำสั่งเหล่านี้คือสิ่งที่คุณสามารถเรียกใช้ได้ใน void loop() เพื่อสร้างภารกิจให้หุ่นยนต์

### 🎯 1. ระบบหลักและการตั้งค่าเซ็นเซอร์ (Core & Calibration)
*   Slide_Calibration(); : ใช้อ่านค่าแสง (พื้นขาว/เส้นดำ) เป็นเวลา 5 วินาที เพื่อคำนวณหาค่ากึ่งกลาง (`ref`) ของเซ็นเซอร์แต่ละตัวโดยอัตโนมัติ
*   isLine(pin); / isFloor(pin); : ใช้เช็คว่าเซ็นเซอร์ตัวนั้น (เช่น `L0`, `R3`) กำลังเจอ **"เส้นดำ"** (`isLine`) หรือ **"พื้นขาว"** (`isFloor`) คืนค่าเป็นจริง (true) หรือเท็จ (false)

### 🏎️ 2. คำสั่งเดินตามเส้นด้วย PID (Smooth Line Tracking)
*   TrackLine(speedL, speedR); : หัวใจหลักของ PID! คำสั่งนี้จะคำนวณความเบี้ยวของหุ่นและปรับความเร็วมอเตอร์ซ้าย-ขวาให้หุ่นอยู่ตรงกลางเส้นเสมออย่างนุ่มนวล
*   ForwardTrackLineTime(speedL, speedR, time_ms); : เดินตามเส้นด้วย PID ตามเวลาที่กำหนด (เช่น 2000 ms = 2 วินาที) แล้วหยุด
*   ForwardTrackLineStop(speedL, speedR, stopSensorPin); : เดินตามเส้นด้วย PID ไปเรื่อย ๆ **จนกว่าเซ็นเซอร์ที่กำหนดจะเจอเส้นดำ** (ใช้บ่อยมากตอนวิ่งไปหยุดรอที่ทางแยกขวาง)

### 🙈 3. คำสั่งเดินแบบไม่มองเส้น (Blind Movement)
*   ForwardDelay(speedL, speedR, time_ms); : เดินหน้าตรง ๆ ตามเวลาที่กำหนด (หลับตาเดิน ไม่สนเส้น)
*   BackwardDelay(speedL, speedR, time_ms); : ถอยหลังตามเวลาที่กำหนด
*   ForwardLineStop(speedL, speedR, stopSensorPin); : เดินหน้าตรง ๆ จนกว่าจะเจอเส้นดำ (เหมาะสำหรับตอนข้ามเส้นปะหรือสะพานที่ไม่มีเส้น)

### 🔄 4. คำสั่งเลี้ยวที่ทางแยก (Intersection Turning)
*   SLsensor(speed, blindDelayMs, stopSensorPin); : **หมุนเลี้ยวซ้ายที่ทางแยก** ตัวหุ่นจะหลับตาหมุนก่อนตามเวลา blindDelayMs (เพื่อให้เซ็นเซอร์หลุดจากเส้นเดิม) จากนั้นจะลืมตาหมุนต่อไปจนกว่าเซ็นเซอร์ stopSensorPin จะสับเจอเส้นใหม่แล้วหยุดเป๊ะ!
*   SRsensor(speed, blindDelayMs, stopSensorPin); : เหมือนข้างบน แต่เป็นการ **หมุนขวา**
*   MotorStop(); : สั่งหยุดมอเตอร์ทันที พร้อมหน่วงเวลาเบรก 100ms เพื่อป้องกันหุ่นยนต์ไถลลื่น

## ภาคที่ 2: 🛠️ คู่มือการทดสอบทีละขั้นตอน (ห้ามข้าม!)
อย่าเพิ่งรีบเขียนโค้ดแก้เขาวงกต! ถ้าหุ่นรวน คุณจะไม่รู้เลยว่าเป็นที่ฮาร์ดแวร์ สายไฟ หรือโค้ด ให้ทำการทดสอบ 4 ขั้นตอนนี้ตามลำดับ

### 🧪 บททดสอบที่ 1: ตรวจสอบเซ็นเซอร์และการคาลิเบรท
**เป้าหมาย:** เช็คว่าเซ็นเซอร์ตาทั้ง 4 ดวงมองเห็นค่าแสงถูกต้องไหม
1. ไปที่ void setup() เอาเครื่องหมาย `//` หน้าคำสั่ง Slide_Calibration(); ออก
2. เปิดสวิตช์หุ่นยนต์ ที่หน้าจอจะขึ้นคำว่า "SCANNING..."
3. **เอามือจับหุ่นยนต์ส่ายซ้าย-ขวาถูไปมา** ให้เซ็นเซอร์ทั้ง 4 ตัวกวาดผ่าน "เส้นดำ" และ "พื้นขาว" สลับกันไปมาจนกว่าเวลา 5 วินาทีจะหมด
4. **✅ สิ่งที่ต้องตรวจสอบ:** ดูที่หน้าจอ GLCD ค่า Min (ตอนเจอเส้นดำ) ควรจะต่ำ (เช่น 100-500) และค่า Max (ตอนเจอพื้นขาว) ควรจะสูง (เช่น 2500-4000) ถ้ามีตัวไหนอ่านได้ 0 หรือ 4095 ค้างตลอดเวลา ให้เช็คสายไฟเซ็นเซอร์ตัวนั้นด่วน!

### 🧪 บททดสอบที่ 2: ทิศทางมอเตอร์
**เป้าหมาย:** สั่งเดินหน้า หุ่นต้องวิ่งไปข้างหน้า
1. ใน void loop() ให้เขียนโค้ดแค่บรรทัดนี้: ForwardDelay(50, 50, 2000); while(true);
2. วางหุ่นบนพื้นและเปิดสวิตช์
3. **✅ สิ่งที่ต้องตรวจสอบ:** หุ่นต้องวิ่งตรงไปข้างหน้า
   * ถ้าหุ่นวิ่งถอยหลัง: ให้ถอดสายมอเตอร์ที่บอร์ด ATX2 สลับขั้วใหม่ (สลับทั้งซ้ายและขวา)
   * ถ้าหุ่นหมุนติ้วอยู่กับที่: แปลว่ามีมอเตอร์ตัวนึงหมุนกลับหลัง ให้สลับขั้วเฉพาะตัวที่วิ่งผิดทิศ

### 🧪 บททดสอบที่ 3: การตอบสนองของ PID เบื้องต้น
**เป้าหมาย:** ดูว่าสมการ PID หักพวงมาลัยถูกทางหรือไม่
1. ตั้งค่าที่ต้นไฟล์ `Movement.ino`: `Kp = 0.02`, `Ki = 0.0`, Kd = 0.0
2. ใน void loop() ให้เขียน: ForwardTrackLineTime(40, 40, 10000); while(true);
3. วางหุ่นบนเส้นตรง วิ่งดู
4. **✅ สิ่งที่ต้องตรวจสอบ:** ลองเอามือผลักหุ่นให้เบี้ยวไปทาง "ขวา" หุ่นจะต้องพยายามหักเลี้ยว "ซ้าย" เพื่อสู้มือเรากลับเข้าเส้น 🚨 แต่ถ้าผลักหุ่นเบี้ยวแล้ว หุ่นยิ่งเลี้ยวหนีเส้นจนตกขอบ แปลว่าคุณเสียบสายมอเตอร์ซ้าย-ขวาสลับกัน หรือ เสียบสายเซ็นเซอร์ซ้าย-ขวาสลับพอร์ตกัน!

### 🧪 บททดสอบที่ 4: การเลี้ยวทางแยก 90 องศา
**เป้าหมาย:** เลี้ยวข้ามทางแยกได้เป๊ะ
1. วางหุ่นให้ตรงกับทางแยกรูปตัว T หรือ 4 แยก
2. ใน void loop() ให้เขียน: SLsensor(50, 200, L1); while(true);
3. **✅ สิ่งที่ต้องตรวจสอบ:** หุ่นจะหมุนซ้าย โดยจะหน่วงเวลาตาบอด 200ms เพื่อข้ามเส้นเดิม แล้วจะไปหยุดดังกึ๊ก! พอดีเมื่อเซ็นเซอร์ L1 สับเข้าเส้นใหม่ (ถ้ามันไปจับโดนเส้นผิดเส้น ให้ลองเพิ่มค่าตาบอดจาก 200 เป็น 300 หรือ 400)

## ภาคที่ 3: 🎛️ คู่มือการจูน PID (Tuning Guide)
การ "จูน" คือการปรับตัวเลข 3 ตัว (`Kp`, `Ki`, `Kd`) ที่อยู่บนสุดของไฟล์ Movement.ino เพื่อให้หุ่นวิ่งได้เร็วและนิ่งที่สุด

*   🏎️ **Kp (Proportional) "พวงมาลัย":** ควบคุมว่าเวลาหุ่นเริ่มหลุดเส้น จะให้หักพวงมาลัยกลับแรงแค่ไหน
*   🛡️ **Kd (Derivative) "โช้คอัพ":** คอยดูความเร็วในการหักพวงมาลัย เพื่อเบรกไม่ให้เลี้ยวแรงเกินไป ช่วยลดอาการหุ่นส่ายเป็นงู
*   🧠 **Ki (Integral) "ความทรงจำ":** แนะนำให้ปล่อยเป็น 0.00 ไว้เลย สำหรับหุ่นเดินเส้น การใส่ Ki มักจะทำให้หุ่นรวนมากกว่าดี

### 📈 ลำดับการจูนที่ถูกต้อง (ทำตามนี้ ประหยัดเวลาไปเยอะ!)
1. **เริ่มจากศูนย์:** ตั้งค่า `Kp = 0.00`, `Ki = 0.00`, Kd = 0.00 และตั้งความเร็ว (speed) ในโค้ดที่ 40
2. **ปรับ Kp ก่อน:** เพิ่ม Kp ทีละ 0.01 (เช่น 0.01 -> 0.02 -> 0.03) 
   * **เป้าหมาย:** เพิ่มจนกว่าหุ่นจะสามารถเข้าโค้งหักศอกได้โดยไม่หลุดเส้น 
   * (หมายเหตุ: ในขั้นตอนนี้หุ่นจะส่ายไปมาซ้ายขวาอย่างรุนแรง... ถือว่าปกติมาก ปล่อยมันส่ายไปก่อน)
3. **ใส่ Kd เพื่อดับความส่าย:** เมื่อหุ่นเข้าโค้งได้แล้วแต่ส่ายเป็นงู ให้เริ่มเพิ่ม Kd
   * เริ่มจาก 0.05 และเพิ่มทีละ 0.05 (เช่น 0.10 -> 0.15 -> 0.20)
   * **เป้าหมาย:** ยิ่งใส่ Kd อาการส่ายจะยิ่งลดลง ให้เพิ่มจนกว่าหุ่นจะวิ่งทางตรงได้นิ่งสนิท และเข้าโค้งได้เนียนตา
4. **เพิ่มความเร็ว แล้วทำซ้ำ:** เมื่อหุ่นวิ่งเนียนสุด ๆ ที่ความเร็ว 40 แล้ว ให้ลองเพิ่มความเร็วเป็น 60 **ระวัง! เมื่อความเร็วเปลี่ยน คุณต้องจูน PID ใหม่** (ปกติจะต้องเพิ่ม Kp อีกนิดนึงให้เลี้ยวทัน และเพิ่ม Kd อีกเยอะ ๆ เพื่อซับแรงเหวี่ยง)
