# 🤖 คู่มือทดสอบการทำงานหุ่นยนต์ PTBOT (Testing Manual)
คู่มือฉบับนี้ใช้สำหรับเขียนโปรแกรมเพื่อทดสอบการทำงานส่วนต่างๆ ของหุ่นยนต์ ทั้งเซ็นเซอร์, แขนจับกระป๋อง, การจัดระเบียบท่าทาง (เซ็ตฉาก), และการเดินนับบล็อก 

---

## 🎯 1. การตรวจสอบค่าเซ็นเซอร์ (Sensor Testing)
ฟังก์ชันเหล่านี้ใช้สำหรับดูสถานะเซ็นเซอร์ต่างๆ ว่าทำงานปกติหรือไม่ก่อนลงสนามจริง

*   👀 **เช็คค่าสี / เส้นขาว-ดำ (Line Sensor)**
    ใช้ฟังก์ชันนี้ใน `setup()` เพื่อให้แสดงค่าบนจอ LCD ของหุ่นยนต์ 
    ```cpp
    ShowValue_Sensor();   // นำค่าไปพลอตกราฟดูค่าแสงของเซ็นเซอร์ทั้ง 8 ตัว
    ```
    > 💡 **Tip:** หากต้องการ Calibrate ค่าให้สว่างที่สุดหรือมืดที่สุด สามารถใช้คำสั่ง `calibrateMinMax();` ได้ 

*   📏 **เช็คเซ็นเซอร์วัดระยะทาง (Ultrasonic & VL53L0X)**
    ใช้ตรวจสอบระยะห่างด้านหน้า ว่าสามารถเจอกระป๋องหรือสิ่งกีดขวางหรือไม่ 
    ```cpp
    ShowDistanceSensor(); // พิมพ์ค่าที่วัดได้ส่งผ่าน Serial Monitor ออกมาดูระยะ
    ```

---

## 🦾 2. การควบคุมแขนและมือจับ (Arm & Gripper Operation)
แขนและชุดจับสามารถควบคุมความสูง การอ้า-หุบซ้ายขวา และคำสั่งแพคเกจหยิบวางที่สร้างไว้แล้ว

*   **ระดับการยกแขน:** ต้องกดแขนให้สุดที่พื้นก่อนเปิดบอร์ด (อ้างอิงที่ `lift(0);` สูงสุดคือ 17)
*   📥 **ฟังก์ชันจับกระป๋อง**
    ```cpp
    pickCan(ความสูงเวลาจับ, NO_SWITCH_LR);  // แบบธรรมดา (จับปกติไม่มีสลับข้าง)
    pickCan(ความสูงเวลาจับ, SWITCH_LR);     // แบบพิเศษ (หยิบแล้วโยนสลับข้างเก็บซ้าย-ขวา)
    ```

*   📤 **ฟังก์ชันวางกระป๋อง**
    ใช้สำหรับวางแล้วผลักพร้อมทิ้งตัวออก 
    ```cpp
    // 🟠 วาง 1 กระป๋อง: placeCan1(ความสูงตอนหย่อน, ระยะห่าง, แขนที่ใช้ ('l'/'r'), ตำแหน่ง ('l'/'c'/'r'/'s'))
    placeCan1(10, 3, 'l', 'c');   

    // 🟠 วาง 2 กระป๋อง: placeCan2(ความสูงตอนหย่อน, ระยะห่าง, มือซ้ายวางไหน, มือขวาวางไหน)
    placeCan2(10, 3, 'c', 'l');

    // 🟢 วางกระป๋องแบบนิ่มนวล ไม่สบัดแขน: 
    placeCan1_NoShake(10, 3, 'l', 's');  // วางตรง ('s' = Straight) ไม่สบัดแขน 
    ```

## 📐 3. การเซ็ตเทียบกำแพงและเส้น (Alignment)
เพื่อรักษาทิศทางและให้หุ่นยนต์ยืนตรง (0 องศา) เราจะให้หุ่นเข้ากำแพงหรือเข้าเส้นสีดำแล้วถอยออกหรือเลี้ยวออก 

*   🧱 **เข้าเซ็ตกับกำแพง (หน้ากระดาน)**
    ฟังก์ชันนี้หุ่นจะเก็บแขนให้อัตโนมัติ จากนั้นเดินดันกำแพง และเดินถอยหลังออกมาตาม Timer พร้อมหันหัวเลี้ยวตามที่ตั้งค่า
    ```cpp
    SetFront_Wall(ความเร็ว, Timer, โหมดการเลี้ยว);
    
    // ตัวอย่างการใช้งาน: 
    SetFront_Wall(40, 300);       // เดินชนกำแพงเซ็ตตัวแล้วถอยหลัง 300 ms 
    SetFront_Wall(40, 300, 'R');  // ดันกำแพงแล้วถอย จากนั้น หมุนเลี้ยวขวา 90 องศา
    ```

*   ⬛ **เข้าเซ็ตกับเส้นสีดำด้านหน้า (SetFront) / เส้นดำด้านหลัง (SetBack)**
    เมื่อเจอเส้นเซ็นเซอร์ หุ่นจะปรับทรงตัวเองแล้วหนีเส้น 
    ```cpp
    SetFront(25, 200);        // เซ็ตเส้นหน้า แล้วถอยลงมา 200 ms 
    SetBack(25, 200);         // เซ็ตเส้นหลัง แล้วเดินหน้าหนี 200 ms

    // 🔥 การพ่วงคำสั่งเลี้ยว
    SetFront(25, 200, 'L');   // ชนหน้าเสร็จ -> หมุนเลี้ยวซ้าย
    SetBack(25, 200, 'r');    // ชนหลังเสร็จ -> โค้ง(เทิร์น) เลี้ยวขวา 
    ```

## 🏁 4. การเดินหน้า/ถอยหลังข้ามช่องตาราง 1, 2, 3, 4 บล็อก
ใช้สำหรับการข้าม Field ไปตามล็อค การเพิ่ม Option ทิศทางในการเลี้ยว `'L'` (ซ้าย) / `'R'` (ขวา) จะมีไจโรชดเชยค่าองศาไม่ให้เดินเบี้ยว

**📌 ระยะอ้างอิงแบบคร่าวๆ จากตัวอย่างการเซ็ตค่าเดินช่อง :**
*(ควรปรับแต่งตัวเลข Timer (เลขเวลา) เพื่อให้เข้ากับแบตเตอรี่หน้างานเสมอ)*

### 🚀 เดินหน้าใช้ฟังก์ชัน `FF(ความเร็ว, เวลา, การเลี้ยวจบ);`
```cpp
// 🟢 เดิน 1 ช่อง / 1 บล็อก
FF(60, 520);         // หยุดนิ่ง
FF(60, 520, 'L');    // เดินไปสองช่องแล้วหมุนตัวไปทางซ้าย 

// 🟢 เดิน 2 ช่อง / 2 บล็อก
FF(80, 720, 'r');    // สังเกตถ้าเป็นตัวเล็ก ('r') จะทำการโค้งวงเลี้ยวแทนสปินตัวตรง 

// 🟢 เดิน 3 ช่อง / 3 บล็อก (วิ่งยาวทะลุกระดาน)
FF(80, 970); 
FF(80, 970, 'R');
```
*Note: ถอยหลังเข้าช่องจะเปลี่ยนจากตัวย่อ `FF` เป็น `BB` แทน (เช่น `BB(40, 510)` เป็นต้น)*

---

### 🌟 ระบบการเดินนิ่งเสถียรพิเศษแบบอัตราเร่ง (motorTimeDegree_Enhanced)
ฟังก์ชันนี้ออกแบบมาเพื่อควบคุมแรงเหวี่ยง ลดปัญหาจานหลุดเวลาวิ่งไกล หุ่นจะค่อยๆเร่ง -> วิ่งเต็มแม็กซ์ -> ลดความเร็วก่อนหยุด แบบสมูธ (Smooth)

```cpp
motorTimeDegree_Enhanced(ความเร็วออกตัว, ความเร็วท็อป, เวลารวม, โหมดการเลี้ยว);
```

**✅ ตัวอย่างวิธีใช้:**
```cpp
// 🌟 ข้ามบล็อกใกล้ๆ นุ่มๆ 
motorTimeDegree_Enhanced(30, 60, 300);

// 🌟 เดินระยะทาง 3 ช่อง เร่งแล้วหมุนเลี้ยวเข้าซ้าย ('L')
motorTimeDegree_Enhanced(30, 80, 720, 'L');

// 🌟 เดินระยะทางยาวทะลุกระดาน (4 ช่อง) ป้องกันหุ่นหัวคว่ำก่อนหยุด จากนั้นเทิร์นซ้าย('l')
motorTimeDegree_Enhanced(40, 100, 970, 'l');
```

### 📝 คำศัพท์โหมดการเลี้ยวท้ายสุด (Option ตัวเลือกคำสั่งตัวอักษร)
ทุกๆฟังก์ชันการเดิน (เช่น `FF`, `BB`, `SetFront`, `motorTimeDegree_Enhanced`) จะสามารถแทรกตัวแปรสคริปเลี้ยวต่อไปนี้ด้านหลังพารามิเตอร์สุดท้ายได้ 
*   `'L'` : หมุนเลี้ยวซ้ายทันทีรอบตัวเอง -90 องศา (Spin Left)
*   `'R'` : หมุนเลี้ยวขวาทันทีรอบตัวเอง 90 องศา (Spin Right)
*   `'l'` : เดินหน้าวงกว้าง เลี้ยวโค้งซ้าย (Turn Curve Left)
*   `'r'` : เดินหน้าวงกว้าง เลี้ยวโค้งขวา (Turn Curve Right)
